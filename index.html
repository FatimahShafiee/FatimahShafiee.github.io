About This Portfolio

I am a Bachelor of Information Technology student at Universiti Kebangsaan Malaysia. This portfolio documents my progress in learning Android mobile application development using Kotlin, Jetpack Compose, and modern mobile architecture.

SDG 4: Quality Education

I chose SDG 4 because quality education helps students improve their knowledge, skills, and future opportunities through accessible and engaging learning experiences.

App Theme: FunLearn — an education-focused app designed to make learning more interactive, motivating, and connected.

Lab Submissions

Labs 1–5

Lab 1

Basic UI with Jetpack Compose

In Lab 1, I learned how to build a basic user interface using Jetpack Compose layouts such as Row, Column, and Box. This lab helped me understand the foundation of mobile UI development.

Lab 2

Interaction and State

In Lab 2, I learned how to manage user interaction using TextField, Button, and state management. I understood how UI changes dynamically based on user input.

Lab 3

Material Design

In Lab 3, I applied Material Design concepts such as themes, colors, typography, cards, and animations. This improved the visual consistency and user experience of my application.

Lab 4

Navigation and ViewModel

In Lab 4, I implemented Navigation and ViewModel. I learned how to manage multiple screens and preserve data across screen transitions.

Lab 5

Room Database

In Lab 5, I integrated Room Database to store data locally. I learned the relationship between Entity, DAO, Repository, and ViewModel in Android architecture.
